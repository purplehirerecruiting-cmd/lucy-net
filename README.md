# ЛЮСИ.НЕТ

Личный цифровой дом Люси из вселенной **SPHYNX VALE / LK Studio**.

Это не корпоративный сайт, не магазин и не обычный лендинг. ЛЮСИ.НЕТ — собственная социальная сеть Люси: его профиль, личная лента, жалобы на Кожаную, рисунки Мини Человека, публикации Sphynx Vale, бесплатные стикеры и редкие коммерческие ссылки на продукты LK Digital.

## Зафиксированные правила

- сайт сам является главным социальным пространством Люси; внешние соцсети не обязательны для запуска;
- Telegram / MAX / VK прежде всего могут быть точками выдачи стикеров;
- без регистрации, пользовательских аккаунтов, профилей, паролей, email и телефонов;
- без пользовательских постов, личных сообщений и обычных комментариев;
- один посетитель может выбрать одну Lucy Reaction на пост и переключить её;
- пять реакций: **Ну конечно / Осуждаю / Жизненно / Нужен кофе / Пиздец**;
- на MVP реакция хранится локально в браузере; позже подключаются только агрегированные серверные счётчики без пользовательской БД;
- mobile-first;
- визуально: графит, тёмный фиолетовый, тёплый коричневый, кремовый, античное золото;
- визуальный язык Sphynx Vale, но интерфейс значительно спокойнее и чище обложек;
- Люся остаётся взрослым серьёзным сфинксом: сухой юмор, усталость, интеллект, сарказм, минимум гримас;
- Кожаная — взрослая создательница за кадром, которую Люся регулярно осуждает;
- Мини Человек — ребёнок за кадром; никакого имени, возраста, фото и персональных данных;
- рисунки Мини Человека не приводятся к стандартам LK Studio, не исправляются и не AI-улучшаются;
- коммерческий контент не должен захватывать ленту: ориентир **70% Люся/юмор/жизнь, 20% Sphynx Vale/лор, 10% продажи**;
- CTA пишутся голосом мира: «Посмотреть последствия», «Забрать Люсю», «Посмотреть очередную эксплуатацию кота» и т. п.;
- `lk-digital-yandex` не трогаем: сайт живёт отдельным проектом и не вмешивается в выдачу цифровых товаров;
- пользовательский домен подключается позже. До покупки домена можно использовать временный Cloudflare URL.
