- без пользовательских аккаунтов;

## Ближайшие этапы

1. Финальный визуальный и мобильный QA живого сайта.
2. Проверка 404, внешних ссылок, якорей и превью ссылки.
3. Зафиксировать `https://lusy.space/` как постоянную QR-точку входа.
4. Создать QR и встроить его в PDF-продукты Sphynx Vale / LK Studio.
5. По мере появления реальных товарных ссылок добавлять продуктовые посты.
6. Позже — Мини Человек, сезонные акции и новые стикеры без изменения ядра сайта.
