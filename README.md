# ЛЮСИ.НЕТ

Личный цифровой дом Люси из вселенной **SPHYNX VALE / LK Studio**.

Это не корпоративный сайт и не обычный лендинг. ЛЮСИ.НЕТ — персональная лента Люси: посты, жалобы на Кожаную, рисунки Мини Человека, публикации Sphynx Vale, бесплатные стикеры и редкие коммерческие ссылки на продукты LK Digital.

## Базовые принципы

- без регистрации и пользовательских аккаунтов;
- без комментариев и пользовательских постов;
- с кастомными реакциями Люси;
- mobile-first;
- визуально: графит, тёмный фиолетовый, тёплый коричневый, кремовый, античное золото;
- визуальный язык Sphynx Vale, но интерфейс спокойнее обложек;
- сайт должен жить отдельно от `lk-digital-yandex` и не ломать существующую выдачу цифровых товаров.

## Первый этап

1. Каркас сайта и визуальная система.
2. Профиль Люси и центральная лента.
3. Посты Люси / Кожаной / Мини Человека.
4. Lucy Reactions.
5. Страницы/блоки Stickers, Sphynx Vale, Bonuses.
6. Подготовка к деплою на Cloudflare.
